# ReelDock · 影坞：验收标准

此清单用于后续实现与联调，当前不是已执行测试报告。P0 确定真实 OpenList 驱动和 Kodi 版本后补充实测结果。

## 1. 执行顺序与字幕规则

所有音轨 / 内置字幕 / 外挂字幕内容场景都以基础 NFO / 图片 / 演员资产已全部远程验证、TMDB 明确非中文为前提；中文分支直接跳过这些检查。扫描时可以登记字幕文件存在性，不得因此提前解析字幕或读取视频内容。

| 场景 | 预期 |
| --- | --- |
| TMDB 尚未匹配、基础 NFO / 图片 / 演员任一必需项未通过 | FFprobe / FFmpeg、视频 Range 哈希、射手查询 / 下载调用次数全部为零 |
| TMDB original_language=zh，基础资产已通过 | skipped_tmdb_chinese，零探测、零视频内容读取、零射手请求 |
| TMDB original_language=cn，基础资产已通过 | 按中文集合跳过探测，不漏掉该语言分支 |
| TMDB 中文，但文件实际是外语配音 / 已有损坏字幕 | 默认规则仍跳过，不能为了验证这一点启动探测 / 读取字幕内容 |
| 请求 language=zh-CN，但 original_language=en | 按非中文处理，不因中文标题或返回语言跳过 |
| 制片国家包含 CN 或 spoken_languages 含 zh，但 original_language=en | 按 original_language 分流，仍进入非中文分支 |
| TMDB original_language 缺失 / 无法识别 | 待确认，不默认当成中文通过 |
| TMDB 非中文，默认音轨中文，无字幕 | 字幕不需要，其他必需项通过后可归档 |
| 默认音轨英语，同时有非默认中文音轨，无字幕 | 仍需补外挂，不把“存在中文音轨”当作默认中文 |
| 默认音轨英语，有确认的完整内置简体字幕 | 不必补外挂 |
| 默认音轨英语，仅内置繁体或英文字幕 | 无有效外挂时必须下载 |
| 默认音轨英语，内置 `chi` 但无法确认繁简 | 不直接认定满足；补下载或人工确认 |
| 默认音轨英语，仅简体 forced / 解说字幕 | 不满足完整内置字幕要求 |
| 默认音轨英语，已有有效英文外挂 | 按确认的需求满足，不重复下载 |
| 已有字幕为空、HTML、损坏或属于其它视频 | 不满足，展示具体原因 |
| `.idx/.sub` 缺失任一部分 | 不满足有效外挂要求 |
| 音轨语言未知或多个默认轨冲突 | 待确认，不自动归档 |
| 射手无结果、超时、返回坏链接或无效字幕 | 分别展示错误，源目录保留 |
| 下载字幕有效但明显季集号 / 片长不符 | 待确认或拒绝，不只检查文件存在 |
| 内置图片字幕不能确认繁简 | 不做未经验证的简体判定 |
| 更换 TMDB ID / original_language、源快照或策略版本 | 旧字幕判定失效，按新状态重算；有效基础资产可按版本规则复用 |

通过记录任务阶段和 Provider 调用顺序，验证基础资产全部读回通过早于任何探测 / 字幕请求。中文分支 NFO 不包含伪造的实际音轨 / 编码信息，界面不得显示“已探测中文”或“字幕已下载”。

## 2. 存储、媒体探测与扫描

- Unicode、空格、`#`、`%` 路径不会被重复转义或错误定位。
- PROPFIND 的 207 响应逐条解析，子项失败不能隐藏。
- 输入 / 输出目录相同、互为上下级、归档 WebDAV 根目录等无效配置被拒绝。
- 两次扫描稳定前不启动归档；处理过程中新增集或文件变化会使最终快照检查失败。
- 样片、下载临时文件按规则忽略；普通附件随整个包保留并核对。
- Range 正确时，远程哈希与本地文件哈希一致；请求顺序与射手协议一致。
- Range 被忽略返回 200 时中止读取，不意外拉取整部视频。
- 错误 Content-Range、短读、源文件变化、302 重定向和链接过期有可恢复错误。
- WebDAV Authorization 不转发给不同主机的下载地址，凭证不出现在探测子进程参数、前端和日志中。
- TMDB 非中文分支的 FFprobe 超时 / 读取预算生效；尾部索引文件在支持范围内可探测，失败有明确原因。

## 3. TMDB、NFO 与图片

- 显式 ID 正确匹配，错误 ID 明确失败；同名、年份冲突和剧集混淆进入待确认。
- 中文文本缺失按字段回退，中文图片缺失使用候选回退。
- 基础 NFO 无探测依赖，XML 能被解析，特殊字符正确转义，uniqueid、类型和季集号正确；未知 streamdetails 省略。
- 已有 NFO ID 冲突或用户修改时保留原件；观看进度不被覆盖。
- 图片需能实际解码，HTML / 空文件 / 截断图片不能视为成功。
- 海报 / 背景图来源缺失时阻塞或人工补齐，不能伪造成功。
- 演员来源无图与下载失败区别显示；来源有图的必需头像失败会阻塞。
- `.actors` 命名与 NFO 演员名一致；重名和非法字符不会静默覆盖其它演员。
- Kodi 的首次导入及刷新均能使用本地头像；清空测试库缓存后、播放端外网断开时仍通过。
- 管理界面图片来自后端缓存，浏览器不需要 TMDB 凭证。

## 4. 上传与移动故障注入

| 故障 / 场景 | 预期 |
| --- | --- |
| 某必需文件获取失败 | 不进入 ready_to_archive |
| PUT 返回成功但读回哈希不一致 | 校验失败，不移动 |
| 上传中断 / 重启 | 保留检查点，重试未验证项，不重抓全部资产 |
| 所有基础资产已传，但非中文分支要求的字幕未下载 / 未传 | 不移动 |
| 中文分支所有基础资产已验证，字幕 skipped_tmdb_chinese | 字幕策略通过；最终清单与其余门槛通过后允许归档 |
| 清单上传失败 | 不移动 |
| 目标同名目录已存在 | Overwrite: F，冲突，不替换目标 |
| MOVE 返回 207 且部分子项失败 | 归档未完成，报告受影响路径并核对状态 |
| MOVE 超时但服务器实际已完成 | 重启核对包 ID 和目标清单，修复为已归档 |
| MOVE 实际失败，源完整目标不存在 | 在安全条件下允许重试 |
| 源目标均存在或出现部分移动 | move_unknown / 冲突，不自动删除任一侧 |
| MOVE 后源目标都不存在 | 严重异常，停止该包并报告 |
| 目标已存在但包 ID 与任务不一致 | 不能当作上次移动成功 |
| 数据库提交失败但远程已移动 | 用持久化归档意图和清单恢复 |
| 不支持 MOVE / 跨存储行为未经验证 | 只刮削，阻塞自动归档，不自动下载复制整部视频 |
| 重复扫描 / 重复点击 / 两个执行者竞争 | 一个包只能被一个有效租约处理 |

核对视频时通常仅比较路径、大小和可靠的版本信息；这不等于全文内容校验。存储原生移动能力的信任边界必须在兼容性文档中写明。

## 5. 电视剧

- 剧 / 季 / 集层级及共享图片继承正确，不把每集都当成电影。
- 剧集继承剧级 original_language；中文剧每集均零探测，非中文剧在全包基础资产通过后按实际音轨逐集判断。
- 包内任何一集字幕或 NFO 失败阻塞整个包，补齐后局部重试成功。
- 当前稳定包中全部现有集通过即可归档，不要求未下载的季集。
- Specials、中文季集名与不明确编号分别有正确处理 / 待确认状态。
- 多集单文件未被支持时必须明确标识，不生成错误的单集 NFO。
- 归档目标已有剧目录时 V1 阻塞，不能进行未经设计的覆盖或合并。

## 6. 界面、Docker 与运行维护

- 列表逐项显示远程验证状态、字幕判定原因与归档阻塞条件。
- 存在但未验证的文件不能显示成已完成；“不需要”与“来源无图”不显示成下载成功。
- 中文分支分别显示 TMDB 原始语言、实际音轨“未探测”、字幕“依据 TMDB 中文规则跳过”；不能混淆作品语言与文件音轨语言。
- SSE 中断后能重新获取正确状态，批量操作不会吞掉单项失败。
- NAS 重启 / 容器重建后配置、主密钥、任务及历史保留。
- 指定 UID/GID 下运行，容器无需特权、宿主机 Docker socket 或媒体盘挂载。
- 实际飞牛 Compose 部署成功，容器内可访问 OpenList、TMDB 和射手。
- 数据库位于本地文件系统，备份恢复包含与密钥有关的必要数据。
- 升级迁移、兼容性不匹配时的备份回退和优雅退出经过验证。
- 管理 API 需要登录，凭证脱敏，归档及写配置操作具有请求来源校验。
- 关于页包含 TMDB 要求的标识与声明。
