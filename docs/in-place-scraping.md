# 多目录原地刮削

当前版本只在媒体所在目录生成刮削数据，不执行归档或移动。

## 配置

- WebDAV 地址、账号、密码与 TMDB 凭证保持原来的配置方式。
- `scrape_paths` 为 1–32 个刮削目录，使用相对于 WebDAV 端点的绝对路径，例如 `["/电影", "/电视剧"]`。路径去重，重叠目录只扫描一次；不允许 WebDAV 根目录或路径穿越。
- 每部电影或电视剧使用独立目录；可以配置媒体库父目录，也可以直接配置某部电影或剧集目录。一次扫描通过即可刮削，不再等待稳定窗口或要求二次扫描；旧配置中的 `stable_seconds` 自动忽略。升级前显示“等待稳定”的记录，重新扫描一次即可更新为“可刮削”。
- `scrape_actor_images` 默认 `false`。关闭时保留演员姓名、角色和 NFO 演员信息，但不下载、生成或重试演员头像；已有头像文件不会被删除。开启后使用 `actor_limit`（默认 20，0 为全部）与 `actor_policy`。
- 管理员初始化密码最少 8 位，原有账户与密码继续有效。

## 浏览与分页

“电影与剧集”和“海报墙”均默认每页 100 部。在列表上方的“每页显示”输入框中可填写其他正整数，修改后回到第一页。两个页面分别记住各自的每页数量，保存在当前浏览器中，刷新或重新打开仍生效。搜索、筛选后按所选数量分页；不足一页时也能修改数量。

## 处理流程

扫描目录 → TMDB 匹配 → NFO / 海报 / 背景等资产上传与读回验证 → 字幕策略 → 最终清单验证 → 完成。NFO、图片、字幕与 `.reeldock` 清单保存在对应媒体目录；视频文件名与目录位置不变。

仍识别 `.part` 等下载临时文件、未知 / 零字节视频、目录混装和季集号冲突，这些情况会提示具体原因。刮削期间仍核对源文件身份，发现变化后停止当前任务并提示重新扫描；单次重新扫描确认当前目录后即可继续，无需等待。请在下载或复制完成后扫描，普通视频文件名持续增长但没有临时文件标记的情况不再通过时间窗口推断。

文件名中的 TMDB ID 优先级最高，高于目录 ID、手工选择和 IMDb 线索。支持在文件名任意位置使用 `{tmdb-27205}`、`{tmdbid-27205}`、`{tmdb=27205}`、`{tmdbid=27205}`、`[tmdb-27205]`、`[tmdbid-27205]`、`[tmdb=27205]`、`[tmdbid=27205]`，标记不区分大小写，适用于所有已支持的视频后缀。识别后直接按 ID 获取 TMDB 资料，不再搜索片名；ID 不存在时提示错误，不回退到片名匹配。电视剧也识别单集文件名中的剧级 TMDB ID；同一剧包的文件名 ID 必须一致。已有 NFO 继续核对身份并原样保留，身份冲突时停止刮削。

没有文件名 TMDB ID 时，仍优先使用手工指定、目录和已有 NFO 中的明确 ID，冲突时提示确认。需要搜索片名时，电影和剧集候选按置信度排序，最高候选**超过 80%**时自动选择，即使存在同名或分数接近的候选。最高置信度为 80% 或更低、或没有候选时仍需人工确认。升级前因匹配歧义阻塞的任务，点击“重试失败项”即可应用新规则。

新生成的电影、电视剧及单集 NFO 同时写入 `<tmdbid>` 和 `<uniqueid type="tmdb" default="true">`，值为对应 TMDB 条目的 ID。已有 NFO 不补写、不迁移；仅在后续生成新 NFO 时写入该字段。

## 增量刮削与重新刮削

“批量刮削”“原地刮削”“启动原地刮削”统一采用增量流程。已保存的匹配资料复用，不重复请求电影详情、演职员和图片列表；已有 NFO、图片和字幕通过身份 / 内容校验后原样保留，不重新下载或覆盖。图片也识别现有的 PNG / WebP / JPEG、`folder` 以及带视频名的海报 / 背景图。缺少的文件才补齐，优先复用本地已验证缓存；清空本地缓存也会先读回远端已有文件。文件无效或身份冲突时展示原因，不用盲目覆盖解决。

已校验或人工确认的内置字幕会在该影片目录中生成 `.reeldock/embedded-<媒体路径摘要>-<内容摘要>.json`。其中保存相对视频路径、长度、ETag / 修改时间、所选轨道、判断依据和已有探测结果。重复刮削、重新扫描、重建数据库后，只要源身份和字幕策略仍一致，就从标志文件恢复结果，不再读取视频探测字幕。ETag 缺失时要求有效的修改时间；缺少可核对身份、标志损坏或源变化时重新探测。旧版本已确认的内置字幕，升级后执行一次增量刮削即可补写标志，无需重新确认或探测。

需要清空后重新刮削时，在“电影与剧集”的影片详情或海报墙详情点击“删除元数据”。先查看具体文件清单，再点击“删除所列元数据”：删除该影片匹配的 NFO、海报 / 背景 / 演员 / 季集图片、关联外挂字幕、内置字幕标志和 ReelDock 清单，清除对应数据库刮削 / 探测记录和人工匹配选择；视频、无关图片、其他影片字幕和普通附件保留。电视剧按当前整剧目录处理，不单独清空某一集。

删除为持久化后台任务，执行时检查媒体快照及所列文件是否仍与预览一致；刮削与删除不能并发。中断后可以重试继续核对已删除文件。确认全部删除后将该影片恢复为待刮削，旧任务和搜索结果失效，之后再点击原地 / 批量刮削即可重新生成数据。该操作需要 WebDAV 账户具有 DELETE 权限，不要求重新初始化管理员或数据库。

内置 PGS / VobSub 等图形字幕，若语言或标题明确标记简体（含“简中”“简英双语”），且不是强制、解说或仅标牌字幕，直接使用内置字幕，不再查询或下载外部字幕。多条合格字幕优先使用默认轨；判定依据为轨道标签，不做 OCR，详情中明确显示这一依据。仅有 `chi` / “Chinese” 标签、繁体或繁简冲突的轨道不按简体处理。此前因此下载失败的任务，升级后重试即可复用已保存的探测结果重新判定。

## 自动字幕下载

自动下载和手动搜索统一使用 ASSRT 及设置中保存的同一个 `assrt_token`，不再请求 `shooter.cn` 或计算旧射手文件指纹。需要补字幕而未填写 Token 时显示“请先配置 ASSRT Token”；TMDB 中文作品、默认中文音轨、合格内置简体字幕或有效外挂仍直接满足字幕策略，无需 Token。

自动搜索使用视频文件名（不含扩展名），通过 ASSRT 的 `no_muxer=1` 忽略压制组和视频参数。优先简体、双语字幕，在前五个搜索结果中逐个尝试支持的字幕文件；剧集核对文件或单集发布信息中的季集号，整季包只选择对应一集，无法明确对应时保留为待处理。无匹配、Token 无效和服务限流分别展示原因；限流走现有任务退避重试。

下载 SRT / ASS / SSA 后验证文本格式、对白和时间轴，原地保存并完整读回；HTML、空内容和无效字幕不会应用。时间轴校验不保证逐句同步，匹配不合适时可通过详情页手动搜索并选择其他版本。

## 确认使用内置字幕

默认音轨语言未知或存在冲突时，仍先检查已有外挂与内置简体字幕；符合条件的字幕可直接满足字幕策略，无需为了判断是否下载而阻塞。未能通过自动校验时，可在“电影与剧集”的影片详情或海报墙详情中，找到“实际探测证据 / 音轨与字幕探测”，点击相应字幕轨道旁的“使用此字幕”，再点击“确认使用，免下载”。电视剧在对应单集的展开详情中操作。

确认表示用户已核实该轨道包含完整的简体中文或简英双语对白。此操作无需 ASSRT Token，不再次提取字幕，也不下载或导出外挂；依据明确记录为 `verification=manual_confirmation`，不冒充文本自动校验，音轨语言保留原有探测结果。操作仍核对已验证的基础资产、媒体长度 / ETag 和当前版本，音频或视频轨道不可作为字幕选择。

所选轨道和人工确认依据保存到当前媒体记录、目录标志文件及最终清单。重试复用该确认，源文件或字幕策略变化后重新核对；只要源身份仍相符，标志也可用于恢复丢失的本地记录。只更新所选电影或单集，其他未处理集仍需各自满足字幕策略；全部通过后自动更新最终清单。

## 手动搜索与应用字幕

自动字幕匹配失败后，可在“电影与剧集”中点击片名，在详情的“手动搜索字幕”中操作；海报墙影片详情的“刮削结果”也提供同一入口。

1. 在设置的“字幕下载来源”中填写个人 ASSRT Token，获取入口为 [ASSRT 用户面板](https://assrt.net/usercp.php)。Token 加密保存，不回显；留空保留，勾选清除才删除。
2. 搜索栏默认使用自动匹配时的视频文件名（不含扩展名），可改成片名、年份或发布版本，关键词至少 3 个字符。电视剧先选择需要处理的一集。
3. 点击“搜索字幕”，结果显示字幕标题、发布版本、语言与格式。选择某个结果后，若包含多个字幕文件，再明确选择一个；只有一个文件时自动选中。
4. 点击“应用所选字幕”，后台任务会下载 SRT / ASS / SSA 文件，验证格式与时间轴，保存到所选视频所在目录，并完整读回验证。结果会显示在当前详情和任务中心。字幕来源为 ASSRT，不在浏览器暴露 Token 或临时下载地址。

应用只处理所选电影或剧集，不重新抓取已验证的元数据、海报或已保存的探测结果。新增 ASSRT Token 后无需重新扫描或刮削基础资产；实际媒体发生变化时仍会停止并要求重新扫描。字幕命名为 `<视频文件名>.assrt.<内容哈希>.srt/ass/ssa`，保留已有文件；所有集均满足字幕策略后更新最终清单，仍有缺字幕的集会继续显示待处理。搜索结果有效期为 30 分钟，过期或影片信息变化后需重新搜索。

ASSRT 接口和凭证说明见 [官方 API 文档](https://assrt.net/api/doc)。字幕服务由 [assrt.net](https://assrt.net) 提供，API 使用 `api.assrt.net`；网页入口 `2.assrt.net` 无需填写到下载主机配置。

海报墙支持类型、刮削完成状态筛选。基础已完成的作品可先查看海报和资料；完整任务完成后标为「全部完成」。字幕失败保留已完成资产，重试继续处理失败阶段。

“电影与剧集”默认只显示当前媒体，列表和目录树会隐藏“源已消失”及已归入剧包的旧记录。“源已消失”表示上次扫描未找到源媒体，不会删除刮削和任务历史；可在状态筛选中选择“源已消失”查看。源文件恢复后重新扫描，记录会回到当前媒体列表。历史记录不能勾选进行批量刮削。

## 从旧版本升级

旧加密配置中的 `input_path` 自动转换为单个 `scrape_paths` 目录；`output_path` 与 `move_verified` 不再生效或出现在设置页。旧版本没有头像开关时，升级后默认关闭头像刮削。需要继续管理旧输出目录中的作品时，可将该目录手动加入刮削目录列表。

已有 ASSRT Token 继续使用，无需重新填写。旧 `subtitle_download_hosts` 配置自动忽略，设置页不再显示“射手字幕下载主机”；已下载并验证的字幕保留。原有 P0 / P3 射手协议工具和相关报告仅用于历史验证，不属于当前自动下载流程。

已完成任务、媒体资料和旧归档记录仍保存在数据库。旧任务待执行的归档步骤会跳过，不会发起 MOVE，也不会重新核对或改动远端目录；升级前已发生的移动不会被撤销。修改配置后请重新扫描，新的任务会使用当前目录与头像策略。

NAS 更新沿用 [升级命令](upgrade.md)，不需要重新初始化管理员。数据库 schema 保持兼容，更新前的配置和任务不需要手动转换。
