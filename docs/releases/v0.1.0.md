# v0.1.0 发布说明草案

状态：发布准备，尚未正式发布。源码版本保留 `0.1.0.dev1`；本地 `reeldock:0.1.0-local` 是验证标签。本文不代表已存在 GHCR 发布镜像、Git 标签或 GitHub Release。

## 功能

- OpenList WebDAV 扫描、两次快照稳定判断、TMDB 电影及常规剧/季/集匹配与人工修正。
- Kodi NFO、海报、背景、随片 `.actors`；季海报/单集 thumb 独立管理。现有元数据、人工修改和观看进度受保护。
- 整包基础必需资产上传及完整读回后才进入字幕阶段；TMDB original_language=zh/cn 零探测、零视频读取、零射手请求。
- 非中文作品按实际默认音轨、完整内置简体字幕、有效匹配外挂判定；需补字幕时使用射手，失败整包保留。
- 最终清单、安全 MOVE、目标冲突拒绝、持久化意图与中断核对恢复；无自动覆盖、合并、盲删或整视频复制删除回退。
- 目录树、展开表格、资产预览、筛选、批量任务、暂停/重试及 SSE 重连。
- amd64 多阶段生产镜像、单进程 API/Worker、非 root UID/GID、只读根目录、健康检查、日志轮转及优雅退出。
- 本地 SQLite/密钥持久化、在线备份、空目录恢复、迁移前检查、单实例锁和升级回退流程。

## 部署与升级

首次部署见 [部署指南](../deployment.md)，升级前停机备份数据库与 master.key，恢复到空本地目录，见 [升级与回退](../upgrade.md)。不要把数据库放到网络盘，不丢弃密钥，也不要让旧镜像直接读取已升级 schema。自动归档默认关闭，需先验证对应 WebDAV 范围的 MOVE。

CI 区分只构建测试和实际发布。`image.yml` 不推送；`publish-image.yml` 仅手动运行，要求已存在且与源码版本一致的正式版本标签，明确选择 publish。此阶段未运行发布流程。实际发布、打标签和创建 Release 仍需用户明确指令。

## 兼容范围与待验

首要播放端 Kodi；首期仅 TMDB/射手，常规电影和播出季集。目标已有剧目录拒绝合并。不支持多集单文件自动映射、绝对集数/替代组、蓝光原盘/ISO、OCR、跨驱动视频搬运或多节点并发。

只对实际完成的 linux/amd64 测试负责，arm64 未验证。OpenList 的条件 PUT 无法提供跨工具原子互斥，媒体包需独占管理。短合成样本不证明大媒体 seek、字幕命中率或精确时间同步。

本次实际命令、NAS / Kodi 与外部服务验证边界以 [进度](../progress.md)及[兼容记录](../compatibility.md)为准。未通过的真实端到端或故障项目保留未验证，不将 Mock、单项网络检查或本地构建列为飞牛完整验收。

本次已取得的证据：后端 255 / P0 44 / 前端 8 项通过；本机与 NAS 的生产容器各 17 项通过，NAS 仓库 Compose、真实 TMDB/射手公开样本分项和 WebDAV 自建电影/双集剧归档通过。剧包真实 MOVE 后客户端超时注入核对完成，MOVE 各一次。以上不等于完整真实影片及 Kodi 断网验收，具体边界保持上述说明。
